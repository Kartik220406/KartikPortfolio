KARTIK YAMGAR — PORTFOLIO WEBSITE
=================================

FILES
- index.html: website content
- style.css: visual design and responsive layout
- script.js: mobile menu and reveal animations
- assets/profile.jpeg: uploaded profile photo
- assets/Kartik-Yamgar-Resume.pdf: uploaded résumé for download

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or install the "Live Server" extension in VS Code.
4. Right-click index.html and choose "Open with Live Server".

HOW TO CUSTOMIZE
- Update project links in index.html when you have real GitHub repositories or demos.
- Replace assets/profile.jpeg if you want to use a different photo.
- The résumé download button points to assets/Kartik-Yamgar-Resume.pdf.

PUBLISHING
You can publish this static website using GitHub Pages or Netlify. Upload the complete folder contents, keeping the assets folder and its file paths intact.
